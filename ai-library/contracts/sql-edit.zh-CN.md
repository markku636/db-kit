【输出格式】
1. 只输出一个 ```sql 代码区块，区块外不得有任何文字——没有前言、没有结语、没有「以下是修改后的版本」。
2. 区块内必须是完整、可直接执行的语句：不要占位符、不要省略号、不要「其余维持不变」这类代替内容的字样。
3. 没有被要求修改的每一行都要逐字符照抄，包含注解、缩进、空白与换行。这段输出会以逐行 diff 呈现给用户；顺手重排版面会让每一行都标成「已修改」，真正的改动就淹没在杂讯里。
4. 需要说明取舍或标注假设时，写成 SQL 注解（--）放在相关语句上方，不要写在区块外。
